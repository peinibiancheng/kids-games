# 小羊的快乐小游戏 · 2D 版本技术总结

> 单文件、零依赖、纯代码绘制的儿童小游戏合集。主角为小羊（羊年主题）。
> 交付物：`index.html`（约 35 KB），双击即可在浏览器打开，无需服务器、无需联网。

---

## 一、这是什么

一个面向低龄儿童的网页小游戏合集，包含五个小游戏：钓鱼、拔河、滑滑梯、溜冰、采蘑菇。
整体走「小猪佩奇」式的扁平卡通风格：明快的色块、圆润的线条、大字按钮、全程只需点击屏幕（也支持空格键），并配有人声化的鼓励音效与本地星星存档。

| 项目 | 内容 |
| --- | --- |
| 交付形态 | 单个 `index.html`，内嵌全部 CSS / JS |
| 外部依赖 | 无（无图片、无音频文件、无第三方库、无网络请求） |
| 画面来源 | Canvas 2D 绘图指令实时生成 |
| 音效来源 | WebAudio 振荡器实时合成 |
| 目标平台 | 桌面浏览器 + 手机浏览器（自适应缩放） |
| 主角 | 小羊（白色蓬松羊毛 + 奶油色脸，羊年主题） |

---

## 二、用了什么技术

| 层次 | 技术选型 | 说明 |
| --- | --- | --- |
| 渲染 | Canvas 2D | `getContext('2d', { alpha:false })`，所有角色与场景用基础绘图 API 拼出 |
| 分辨率适配 | 逻辑坐标系 1280×720 | 等比缩放 + 居中留边；DPR 上限 2，兼顾清晰度与性能 |
| 输入 | Pointer Events | `pointerdown/move/up/cancel` 统一鼠标与触屏；`keydown` 支持空格/回车 |
| 主循环 | `requestAnimationFrame` | 时间差 `dt` 驱动，带上限防止切后台后跳帧 |
| 音效 | WebAudio API | `OscillatorNode` + `GainNode` 包络合成，无音频文件 |
| 存档 | `localStorage` | 键：`peppa_best`（星星）、`peppa_sound`（声音开关），读取带 `try/catch` |
| 文字字体 | 系统圆体字栈 | `Yuanti SC / 幼圆 / Microsoft YaHei / PingFang SC` |

说明：内部存档键沿用了早期 `peppa_*` 命名，**没有**随角色改名，目的是保留孩子已经积累的星星记录；这些键用户不可见。

## 三、怎么做的（实现思路）

这套做法参考了《几猫国产3A大作_V1.html》的**工程思路**——单文件封装、零外部资源、程序化生成美术、输入统一化——但把渲染从 Three.js 3D 换成了更贴合低龄扁平画风的 Canvas 2D。

### 1. 先搭引擎，再填内容

- **逻辑分辨率固定 1280×720**。`resize()` 计算 `scale`、`offX`、`offY`，`toLogical()` 把任意屏幕上的点击坐标换算回逻辑坐标，因此同一套布局在任何尺寸下都成立。
- **统一输入模型** `P = { x, y, down, pressed, released }`。每帧末清掉 `pressed/released`，UI 命中检测 `inRect()` 只看「这一帧是否新按下」，避免长按被反复触发。
- **主循环** `frame(now)`：算 `dt` → `update(dt)` 更新当前场景 → `render()` 重绘全部 → 递归 `requestAnimationFrame`。场景切换用一个白色 `flash` 遮罩做淡入。

### 2. 所有美术都是代码画的

定义了一层绘图原语：`rr`（圆角矩形）、`ell`（椭圆）、`poly`、`line`、`text/textOut`、`star`；再往上组合成素材函数：`cloud`、`sun`、`hill`、`tree`、`bush`、`flower`、`fence`、`house`，以及主角 `pig(x,y,s,o)`。

> 角色函数虽仍叫 `pig`，但造型已改为小羊：多层白色圆形堆出蓬松羊毛、奶油色脸与口鼻、耷拉耳朵、粉色腮红；衣服颜色区分角色（红=主角、蓝=伙伴、橙=妈妈、蓝=爸爸并带眼镜）。改函数名会导致调用点全改，收益为零，故保留。

动画不预渲染：云飘、太阳转、鱼影游、星星跳、角色轻微上下浮动，都是每帧按时间 `t` 重新计算位置再画。粒子系统 `burst()/updateParts()/drawParts()` 负责迸发的星星、水花。

### 3. 音效现场合成

`sfx(name)` 按名字发不同音：`tap`（点击）、`pop`（拾取）、`yay`（通关琶音）、`splash`（入水）、`boing`（撞击）、`star`（得分）、`woo`（开始）。`tone()` 用 `exponentialRampToValueAtTime` 做音量包络，避免爆音。首次交互时才 `ensureAudio()` 创建/恢复 AudioContext，符合浏览器自动播放策略。

### 4. 场景状态机

`go(s)` 切换场景，并在进入游戏前调用对应的 `xxxReset()` 重置状态。场景包括：`title`（标题）→ `hub`（游戏中心五张卡片）→ 五个玩法 → `result`（结算）。`finish(id, star, count)` 统一处理结算与 `saveBest()` 存档。

## 四、包含哪些功能

### 通用功能

| 功能 | 说明 |
| --- | --- |
| 标题页 | 小羊角色 + 大按钮「开始玩」；提示点击或空格 |
| 游戏中心 | 五个大卡片，各带图标、名称、历史最高星数；顶部显示累计星星 |
| 统一操作 | 全程点屏幕即可；空格/回车等同点击；手机自适应 |
| 顶部栏 | 返回按钮 + 场景名 + 实时计数 |
| 结算页 | 1–3 颗星 + 成绩 + 「再玩一次」/「回到游戏中心」 |
| 星星存档 | 每关取历史最好成绩，存本地 |
| 声音开关 | 一键静音，状态持久化 |

### 五个小游戏

| 游戏 | 玩法 | 目标 / 计分 |
| --- | --- | --- |
| 快乐钓鱼 | 抛竿 → 等待咬钩 → 浮漂剧烈抖动时点击收竿 | 钓满 5 条；星级 `min(3, 1+钓到数/2)` |
| 大力拔河 | 快速连点把小旗拉向自己一侧，对手拉力随时间增强 | 旗子过线判胜；星级按点击次数 `1+次数/18` |
| 滑滑梯 | 点一下爬一级楼梯，到顶自动滑下，途中收星星 | 共 5 颗星；星级 `round(收星数/2)` |
| 溜冰场 | 左右移动躲雪人/路障、收雪花，被撞有短暂无敌 | 30 秒内收雪花：≥8 三星、≥4 两星 |
| 采蘑菇 | 蘑菇冒头就点，金蘑菇 +2，漏掉普通蘑菇会扣 | 45 秒内：≥12 三星、≥7 两星 |

> 难度特意调低：拔河按「每秒约 4 次慢速点击」测试仍能通关，保证孩子能赢。

## 五、代码结构（单文件内的分区）

| 区块 | 位置（约） | 职责 |
| --- | --- | --- |
| 样式与骨架 | 文件头 | 全屏画布、字体、错误提示框 |
| 0. 引擎 | 30–155 行 | 缩放、坐标换算、输入、音效、绘图原语、按钮命中 |
| 场景素材 | 158–290 行 | 云/太阳/树/房子等 + 小羊角色 + 粒子 |
| 存档与配置 | 286–320 行 | `GAMES` 列表、`go()`、`finish()` |
| 通用界面 | 之后 | `drawTitle/drawHub/drawResult/topBar` |
| 五个游戏 | 中段 | 每组含 `xxxReset / updateXxx / drawXxxScene` |
| 主循环 | 末尾 | `update()`、`render()`、`frame()`、启动初始化 |

## 六、怎么运行与验证

- **运行**：双击 `index.html`。
- **语法检查**：抽取 `<script>` 内容后 `node --check`。
- **流程验证**：用 Node `vm` + Canvas 桩模拟环境，跑通「标题→选关→进入→通关→重玩→返回」共 22 项流程断言。
- **视觉验证**：无头 Chrome 逐场景截图，检查文字重叠、按钮遮挡、图标压标题、悬空木条等排版问题并修正。

## 八、已知取舍

- 存档键仍是 `peppa_*`，为保全已有星星记录，不做迁移。
- 2D 版没有独立的源码文件，全部在一个 HTML 里；好处是零构建，代价是单文件较长。
- 所有图形为程序化绘制，风格统一但无法使用孩子自定义的照片素材（若需要则不再是单文件零依赖）。
