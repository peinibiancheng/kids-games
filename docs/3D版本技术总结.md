# 小羊的快乐小游戏 · 3D 版本技术总结

> 与参考项目《几猫国产3A大作_V1.html》同路线的真 3D 版本：Three.js 内联进单文件、低多边形程序化建模、HTML 覆盖层做 UI。主角为小羊（羊年主题）。
> 交付物：`3d.html`（约 650 KB），双击即可在浏览器打开，无需服务器、无需联网。

---

## 一、这是什么

2D 版本的 3D 重制：五个小游戏全部改为真正的三维场景——钓鱼有池塘、木桥与鱼竿浮漂；拔河是两头小羊拉绳；滑滑梯有立体滑道与楼梯；溜冰场是冰面与雪人路障；采蘑菇用射线拾取 3D 蘑菇。选关页从「五张卡片」变成一个可点击站点的 3D 村庄。

| 项目 | 内容 |
| --- | --- |
| 交付形态 | 单个 `3d.html`，内嵌 Three.js + CSS + 游戏 JS |
| 外部依赖 | 无（Three.js 已内联，无图片/音频文件/网络请求） |
| 渲染 | WebGL（Three.js r150，UMD 构建） |
| 画面来源 | 基础几何体程序化拼装 + 灯光 + 阴影 |
| 音效来源 | WebAudio 实时合成 |
| 主角 | 小羊（球体堆羊毛 + 奶油脸 + 耷拉耳朵） |

## 二、用了什么技术

| 层次 | 技术选型 | 说明 |
| --- | --- | --- |
| 3D 引擎 | Three.js r150（`three.min.js`，约 614 KB） | npm 下载 UMD 构建，内联进 HTML |
| 渲染器 | `WebGLRenderer` | 抗锯齿、`PCFSoftShadowMap` 软阴影、`sRGBEncoding` |
| 相机 | `PerspectiveCamera(52°)` | 各场景用 `setCam()` 设定机位，逐帧插值过渡 |
| 光照 | 环境光 + 平行光 | 平行光投影，营造立体与阴影 |
| 材质 | `MeshLambertMaterial` + `flatShading` | 低多边形块面感，材质按颜色缓存复用 |
| 几何体 | Box / Sphere / Cylinder / Cone / Torus / Extrude | 全部角色与道具由这几类拼出 |
| 交互拾取 | `Raycaster` | 村庄站点、3D 蘑菇的点击命中 |
| UI | HTML DOM 覆盖层 | 标题/结算/HUD/提示用 DOM，3D 坐标投影定位站点标签 |
| 动画 | `Clock` + 逐帧 `update()` | 角色摆动、镜头插值、粒子、道具运动 |
| 音效 | WebAudio `OscillatorNode` | `tap/pop/yay/splash/boing/star` 六种 |
| 存档 | `localStorage` | 键：`lamb3d_best`、`lamb3d_sound` |

存档键独立为 `lamb3d_*`，与 2D 版互不干扰。

## 三、怎么做的（实现思路）

### 1. 源码分层，构建时再合并成单文件

3D 版不再把所有东西塞进一个 HTML，而是拆成可维护的源码，最后用一个构建脚本内联打包：

```
kids-games/
├── src/
│   ├── 3d-shell.html   # 界面外壳 + 全部 CSS + DOM 结构（占位符 /*__THREE__*/ /*__GAME__*/）
│   └── 3d-game.js      # 全部 3D 建模、五个游戏逻辑、音效、场景状态机
├── vendor/
│   └── three.min.js    # Three.js r150 UMD（npm pack 取得）
├── build.py            # 把上面三者拼成单文件
└── 3d.html             # 构建产物（交付物）
```

`build.py` 读取三个文件，做两处占位符替换，并断言 `three.min.js` 不含 `</script`（防止内联时提前闭合脚本）。重建命令：

```bash
python build.py
```

这样既保留了工程上的可维护性，又满足了「单文件、零依赖、双击即玩」的交付要求。

### 2. 程序化低多边形建模

封装 `add / box / ball / cyl / cone / torus / rodBetween` 等原语，材料按颜色 `matCache` 复用，避免重复创建。每个场景由 `newScene(bg)` 起步：设置背景色、雾、环境光与投影平行光。

小羊 `lamb(opts)` 用一组球体堆出羊毛，配奶油色脸、圆柱四肢、锥形耳朵、眼球与腮红；`animateLamb(g, energy)` 按时间摆动四肢与身体高度。村庄的树、房子、云、花、山丘、星星（`ExtrudeGeometry`）也都是几何体拼装，`confetti()/burst3()` 做粒子庆祝。

### 3. 场景状态机 + 逐帧插值

`setState(id)` 负责切换场景并 `dispose` 旧资源；`frame()` 每帧插值相机位置 `camPos → camera.position`、更新粒子、把 3D 站点坐标投影到屏幕以定位 HTML 标签。五个游戏各自是一个 `buildXxx()` 返回的对象，含 `update()` 与 `tap()`，主循环统一调用。

### 4. 真 3D 的交互差异

- **采蘑菇**：`Raycaster` 从点击位置发射射线，命中蘑菇网格才计分（不是 2D 的矩形判定）。
- **村庄选关**：每个站点是可拾取的 3D 道具，点击站点进入对应游戏；站名标签是 DOM 元素，靠 `Vector3.project(camera)` 把世界坐标换算成屏幕坐标后定位。
- **钓鱼**：鱼竿末端 `tip` 与浮漂 `bob` 用 `Line` 相连，抛竿/咬钩/收竿都体现为浮漂与鱼在三维空间中的运动。

## 四、包含哪些功能

### 通用功能

| 功能 | 说明 |
| --- | --- |
| 3D 标题页 | 两只小羊 + 房子树木，卡片标题与开始按钮 |
| 3D 村庄选关 | 五个可点击站点，站名与星数标签跟随 3D 坐标 |
| HUD | 返回按钮、场景名、实时计数、累计星星、声音开关 |
| 大号操作按钮 | 屏幕底部「点一下」按钮，大触控面积，适配幼儿 |
| 结算页 | 1–3 星 + 成绩 + 「再玩一次」/「回到村庄」 |
| 本地存档 | 最佳成绩与声音设置持久化 |
| 容错 | 顶层 try/catch，异常时页面显示错误信息便于排查 |

### 五个 3D 小游戏

| 游戏 | 3D 呈现 | 目标 / 计分 |
| --- | --- | --- |
| 快乐钓鱼 | 池塘、木桥、鱼竿线与浮漂、游动的 3D 鱼 | 钓 5 条；星级 `min(3,1+钓到数/2)` |
| 大力拔河 | 两头小羊相对拉绳、中央标记随拉力移动 | 标记过线胜；星级按点击次数 |
| 滑滑梯 | 立体楼梯 + 滑道，沿曲线滑下收 5 颗星 | 星级 `round(收星数/2)` |
| 溜冰场 | 冰面、滑行小羊、雪人路障、漂浮雪花 | 30 秒收雪花：≥8 三星、≥4 两星 |
| 采蘑菇 | 树林中冒头的蘑菇，射线拾取，金蘑菇 +2 | 45 秒：≥12 三星、≥7 两星 |

## 五、关键实现要点与踩坑

| 问题 | 处理 |
| --- | --- |
| Three.js 内联时 `</script` 提前闭合 | `build.py` 中断言检查，构建期拦截 |
| 标题卡片遮挡小羊头部 | 调整标题页为顶部布局、卡片内边距 |
| 鱼竿末端与浮漂脱节 | 用 `Line` 连接 `tip` 与 `bob`，同步更新端点 |
| 雪花在冰面上看不见 | 改为带厚度的立体雪花并提高对比 |
| 结算页星星不点亮 | HTML 星星容器补 `id="result-stars"`，JS 才能选中 |
| 软件渲染环境（无 GPU） | 验证时启用 SwiftShader（`--enable-unsafe-swiftshader`） |

## 六、怎么运行与验证

- **运行**：双击 `3d.html`。
- **重建**：修改 `src/` 后执行 `python build.py`。
- **语法检查**：`node --check src/3d-game.js`。
- **浏览器验证**：用 `puppeteer-core` 驱动系统 Chrome（无需另装浏览器），逐场景：
  1. 截图检查标题页、村庄、五个游戏画面；
  2. 快进 `update()` 把每个游戏跑到结算，核对星星与成绩；
  3. 验证「再玩一次」正确重置、「返回村庄」正常；
  4. 监听 `pageerror` / `console.error`，确认 0 报错。
- 调试钩子 `window.__P3D = { go, current }` 供自动化脚本切换场景与读取状态。
